# .sh ファイルとは何か（読み方・安全な使い方）

## 1. 正体
`.sh` ファイルは**ただのテキストファイル**です。中身は、ターミナルに手で打つコマンドを、上から順に書き並べたもの。
「コマンドを打つ代わりに、まとめて実行してくれる台本」と考えてください。メモ帳で開けば読めます。
この台本を読んで実行するプログラムが **bash**（シェル）で、台本の1行目 `#!/usr/bin/env bash` が「bashで読んでね」という宣言です。

## 2. 実行のしかた
```bash
bash bin/doctor.sh        # 方法1: bash に台本を渡す（いつでも動く）
bin/doctor.sh             # 方法2: 実行権限(chmod +x)があれば直接呼べる
bin/doctor.sh --help      # 多くのスクリプトは使い方を表示する
```
`--run` や `--help` のように `--` で始まる語は**オプション**（スクリプトへの指示）です。

## 3. 実行前に必ずやること（安全の3点）
1. **読む**: `less bin/doctor.sh` または `head -20 bin/doctor.sh`。冒頭のコメント（`#` で始まる行）に目的・使い方・安全性が書いてあります。`#` はコメント＝実行されない説明文。
2. **ドライランで試す**: 本リポジトリの「変更を伴うスクリプト」は、何もしない確認モードが既定です。`--run` を付けて初めて実際に変更します。
3. **消すコマンドを探す**: `rm`（削除）、`mv`（移動）、`>`（上書き）が入っていたら、対象を特定できるまで実行しない。本リポジトリのスクリプトは**何も削除しません**。

## 4. 本リポジトリのスクリプト一覧と危険度
| スクリプト | 何をする | 変更するか |
|---|---|---|
| `doctor.sh` | 環境の健康診断 | しない（読み取りのみ） |
| `cleanup-report.sh` | 容量の報告 | しない |
| `home-inventory.sh` | ホームの棚卸し | しない |
| `normalize-names.sh` | 名前の直し案を画面に出す | しない（出力のみ） |
| `qsub-run.sh` | ジョブ雛形を画面に出す | しない（出力のみ） |
| `bootstrap.sh` | ホームに骨格を作る | `--run` 時のみ。新規作成だけ、既存は触らない |
| `home-organize.sh` | 指定の移動を実行 | `--run` 時のみ。移動だけ、削除しない、undo記録を残す |
| `init-project.sh` | プロジェクト雛形を作る | 新規作成。既存ファイルは上書きしない |
| `render.sh` | 文書の置換コピーを作る | 別ディレクトリに作るだけ |

## 5. 用語
- **終了コード**: スクリプトが終わるとき返す数。0=成功、それ以外=失敗。`echo $?` で見える。`doctor.sh` は「要修正」があると1を返す。
- **冪等（べきとう）**: 何度実行しても結果が同じ。`bootstrap.sh` は2回目以降「既にある」と表示するだけ。
- **ドライラン**: 実際には変更せず「こうします」と表示だけする実行。
- **パス**: ファイルの住所。`~` はホーム、`.` は今いる場所。

## 6. 自分で台本を書くときの最小の型
```bash
#!/usr/bin/env bash
# 何をするスクリプトか（1行で）
set -euo pipefail          # エラーで止まる・未定義変数を許さない（事故防止のお守り）
echo "hello"
```
