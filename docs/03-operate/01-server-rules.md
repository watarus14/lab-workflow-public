# 01 サーバー運用ルール（必読・最重要）

> ⚠️ **計算は必ずジョブスケジューラ（PBS/Torque など）経由で実行する。**
> ログインノード上での計算、および計算ノードへ直接 ssh しての計算は**禁止**です。

## なぜ禁止なのか
サーバーは役割の違う2種類のマシンでできています。
```text
  あなたのPC ──ssh──▶ ログインノード（your-cpu-server / your-gpu-server）
                        │  玄関＋ファイル置き場。全員が使う
                        │
                        └─ ジョブスケジューラ（受付係）──割り当て──▶ 計算ノード群（実際に計算する機械）
```
- **ログインノードは計算機ではありません。** ここで計算を回すと、全員のログイン・エディタ操作・ファイル転送が重くなり、研究室全体の作業が止まります。
- **計算ノードへ直接 ssh して回すと、スケジューラの管理外で動きます。** スケジューラは「どの資源が誰に割り当て済みか」を台帳で管理しています。外から入って勝手に回すと、二重予約・CPUコアの競合・GPUメモリの衝突が起き、正規に `qsub` した他人（や自分）のジョブを巻き添えで遅くしたり落としたりします。順番待ちの公平性も壊れます。

つまりこれは「お行儀」の問題ではなく、**他人のジョブを壊す行為**です。

## 禁止事項と、正しい代替
| ❌ やってはいけない | ✅ こうする |
|---|---|
| ログインノードで `python xxx.py` を直接実行 | ジョブスクリプトにして `qsub`（[03 PBS](03-pbs-jobs.md)） |
| 「ちょっとした動作確認だから」とログインノードで実行 | 短い**対話ジョブ** `qsub -I -l nodes=1:ppn=1 -l walltime=00:30:00` を取り、その中で実行 |
| 計算ノードへ `ssh` して計算 | 必ず `qsub`。様子を見たいだけなら `qstat -n <JobID>` |
| GPU で対話的に試したい | `qjupyterlab` を `qsub`（[03 PBS](03-pbs-jobs.md) §GPU） |
| 終わったジョブ・notebook を放置 | 使い終わったら `qdel <JobID>` で必ず開放（特に GPU は共有資源） |

### 「何が計算で、何が計算でないか」
| ログインノードでやってよい | ログインノードでやってはいけない |
|---|---|
| ファイルの編集・移動・コピー、`git` 操作 | モデルの学習、シミュレーション、大きなデータの解析 |
| `rsync` での転送 | 長時間走る `python` / `jupyter` の実行 |
| `conda env create`（パッケージのダウンロード） | `python train.py` のような重い実行 |
| `qsub` `qstat` `qdel` | 重い前処理・圧縮・展開 |

迷ったら: **「CPUやメモリを数分以上使うか？」使うならジョブに出す。**

## 「対話的に作業したい」ときの正規ルート
ログインノードで回してしまう一番の理由は「対話的に試したいから」です。その用途には**対話ジョブ**があります。
```bash
# 計算ノードを1つ確保して、その上の対話シェルに入る
qsub -I -l nodes=1:ppn=4 -l walltime=01:00:00
#  → プロンプトが計算ノードに切り替わる。あとは普通に python などを実行してよい。
#     exit するとノードが開放される。
```
`qsub -I` なら「対話的な使い勝手」と「スケジューラの管理下」が両立します。GPU で対話的に作業したいときは `qjupyterlab`（[03 PBS](03-pbs-jobs.md)）。

## 困ったとき・大量に資源を使うとき
- エラーを自力で解決できないときは、抱え込まず先輩（サーバー係）に聞く。その際 `qstat -f <JobID>`、出力ファイル（`*.o<JobID>`）、エラーメッセージを添えると切り分けが早い。
- 共有資源を大きく使うときは、**事前に `your-channel` で相談する**。目安:
  - CPU: クラスタ全体の半分程度以上のコア、または複数ノードを長時間（数時間〜）占有するとき
  - GPU: 4枚以上を確保するとき
- 締め切り前など混む時期は特に。`pbsnodes` や `qstat -q` で空きを見て、譲り合い・分割実行で全員が回せるようにする。
